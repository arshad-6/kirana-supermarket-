Kirana AI Agent

An AI-powered Kirana/Supermarket Store Manager that works completely through Telegram.

Features

* AI-powered conversational agent
* Product & inventory management
* Billing & GST calculation
* Customer Khata / credit
* Sales & stock analytics
* GST invoice PDF generation
* Sales report PPTX generation
* Persistent store memory

Tech Stack

Python • Claude • Telegram • FastAPI • PostgreSQL • SQLAlchemy • ReportLab • python-pptx

Architecture

```text
Telegram → Claude AI Agent → Tools → Business Logic → Database
```

Example

```text
"Add 20 packets of rice"
"Bill 2 rice and 1 oil"
"Show today's sales"
"Show Kumar's credit"
"Generate invoice"
```
